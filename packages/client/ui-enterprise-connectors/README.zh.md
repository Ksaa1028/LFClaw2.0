# LFClaw 连接器中心

[English](README.md) | 中文

## 概述

员工可以使用获授权的企业连接器，并管理个人远程与本机连接器。账号设置保留在 Host 或企业服务，渲染层不接收已保存的凭据。工具发现及调用均检查当前授权；账号失效或同步失败会撤回工具。

输入框连接器选择器将所选内容追加到当前会话，保留草稿文字、引用和附件，不自动发送。管理页面的使用按钮开启新会话。

## 连接与权限

员工独立绑定的企业 OAuth 使用桌面 Host 的 `127.0.0.1` 一次性回调。Host 通过当前员工已认证的企业连接提交授权码；发现、PKCE、授权码交换、令牌保存与刷新、工具调用均由企业服务端负责。已配置的企业 IP 地址保持不变，无需公开 OAuth 回调。客户端和服务端都须支持此流程；旧服务端会触发本地化的更新提示。浏览器须运行在 Host 所在机器，服务商须接受本机回调。`oauthFlowTtlMs` 限制等待时间；解除连接、替换授权和 Host 退出会关闭监听。管理员共用账号的 OAuth 保留服务端回调流程。

页面固定标题、页签和搜索栏，连接器卡片在下方剩余区域内滚动。

目录展示复用 Host 快照，最长为 `refreshIntervalMs`；企业目录版本监听持续更新快照。手动刷新、详情、账号操作和工具调用重新请求服务端状态。输入框选择器并行读取轻量企业选项和本机个人选项；员工身份通过 `employee/identity` 校验。选项响应不包含图标、工具定义和连接配置，需要服务端提供轻量接口。

企业连接器在尚无工具时也支持服务端定义的凭据字段、API Token 和浏览器 OAuth。账号可由企业共用或员工独立绑定。渲染层只收到字段描述与状态，不收到已保存密钥；提交包含当前展示配置的摘要，目标变化后须刷新表单。旧公众号绑定继续兼容。非商场已发现工具自动可用，连接器分配范围和启用状态仍生效；商场保留工具和楼层授权。

连接器工具目录序列化后超过 `inlineToolSchemaChars`（默认 16000 字符）时，只向模型提供一个发现与调用入口。`list` 搜索工具名称和说明，`describe` 读取完整定义或其中的 JSON Pointer，`call` 校验原始输入定义后使用原有调用逻辑。发现结果作为工具结果记录。`toolCatalogPageSize`（10）、`toolDefinitionPageChars`（12000）及 `toolSummaryChars`（320）限制每页大小；长定义返回后续偏移，不删除参数约束。企业与个人连接器共用此行为，配置或权限变化使发现与调用失效。小目录保留原生工具名称。这些限制减少单个连接器的声明量，不改变模型配置的上下文窗口。

个人远程连接器支持 OAuth 发现、动态注册、PKCE、令牌刷新和一次性本机回调。预注册公开客户端可填写 Client ID、签发者和 scopes。先保存再在详情连接，浏览器回到本机回调后 Host 刷新工具；`oauthFlowTtlMs` 限制等待时间。令牌按员工存于本机私有目录，修改配置或解除连接后，待完成回调和旧凭据失效。手动 Header 与 stdio 环境变量继续可用。本地解除连接不撤回服务商网站上的授权同意。

连接器卡片显示经过服务端校验的上传图标，未上传时保留默认连接图标。企业 MCP 可使用 Streamable HTTP 或旧版 SSE 与服务端保存的自定义 Header；企业网关按员工权限限制楼层参数，无需修改 MCP 配置。

服务端按连接器设置客户端工具展示状态；关闭后仍显示连接器卡片，但不展示工具名称、数量和说明。已授权工具仍可由智能体调用，调用继续受员工与工具权限约束。

渲染层兼容缺少图标和工具展示字段的旧版 Host 目录：使用默认图标，并在 Host 明确返回展示状态前隐藏工具详情。重新构建此包时须先生成 `lib/types`，再打包，因为 Host 包以生成后的入口为输入。

桌面 Host 通过 `enterpriseConnection` 读取当前员工的连接器目录，激活令牌不会进入渲染层。客户端接口只返回已授权的连接器名称和已配置工具摘要。打开连接器后，由 Host 调用员工工具目录接口检查实时发现是否成功。未知连接器 ID 在转发前被拒绝。已发现且获授权的 MCP 工具会注册到智能体运行时；每次调用仍经过企业服务端，重新校验员工、连接器、工具和商场数据权限。目录获取失败或权限撤回时会清除对应工具注册。

已授权且可连接的工具会自动注册到普通对话。输入框“添加”菜单的连接器选择器按“企业连接器”和“我的连接器”分组，搜索可跨组进行；连接器详情也有“开始使用”。两者会建立带有所选连接器名称的会话草稿，供员工填写具体任务。显式选择不会绕过实时工具发现或服务端授权；隐藏的工具清单在选择器和详情中仍不展示。

没有可用工具的企业连接器不能开始对话或检查工具，也不会出现在输入框选择器中，但账号表单仍可连接并发现工具。商场工具还须管理员授权与员工楼层权限。Host 分别提供工具可用状态和展示状态。

页面分为“企业连接器”和“我的连接器”。个人连接支持 SSE、Streamable HTTP、自定义 Header，以及带参数和显式环境变量的 stdio 命令。员工通过“新建连接”添加连接，通过“查看详情 → 编辑配置”修改已有配置；不提供 JSON 导入。启用的手动配置须在保存前检查；OAuth 配置先保存再进行浏览器授权，停用的配置可离线保存。工具发现失败时不保存并保留表单，HTTP 405 提示核对传输方式。员工还可启停或删除连接。编辑和删除要求修订号与当前一致。目录操作位于页面顶部右侧，搜索框位于标签页下方。

个人设置保存在 `dataDirectory`，按已激活员工 ID 隔离。Host 在配置中保存凭据，返回渲染层的 Header 和环境变量值为空；仅在 URL 或命令未变时，留空才保留原秘密值。Stdio 继承子进程服务清理后的父进程环境并合并用户显式变量。个人工具自动注册，可达时进入输入框选择器。每次执行重新校验员工及保存的修订号；停用、删除、切换账号和插件卸载后不能继续调用。远程请求还会检查企业策略：与商场数据权限连接器同源的服务须通过企业连接器访问。

`requestTimeoutMs` 限制每次连接和工具操作的时间，`maxConfigBytes` 限制管理请求体积。卡片可见不代表服务可达。Host 和企业页通过 `employee/connector-catalog` 修订摘要长轮询；变更会中断旧调用、移除旧工具并更新楼层展示，迟到的发现结果和查询结果不能恢复已失效的一轮授权。同步失败清除工具和授权展示，等待 `refreshIntervalMs` 后重试。服务端以 `mcpTimeoutMs` 限制长轮询等待时间，企业连接超时须大于此值。个人目录刷新单独处理每个 MCP 的故障，其他个人工具继续可用。

<a id="model-experience"></a>
## 模型体验

### 已授权 MCP 工具

#### 模型看到的内容

企业工具使用 `lfclaw_<tool>_<digest>` 名称。企业商场工具说明包含当前授权楼层，参数定义移除服务端身份字段；这些定义及工具结果使用标准会话日志。启用的个人 MCP 工具将发现的参数定义和带连接器名称的说明加入模型请求，调用与结果使用标准 MCP 展示器和会话工具日志。秘密配置值和管理表单不进入模型输入。

#### Token 影响

工具注册期间，每次请求包含其说明和参数定义。调用与结果保留到上下文压缩；停用不用的连接器可减少工具定义的 token 用量。

#### KV Cache 影响

权限修订可能改变工具说明或移除工具，从第一个变更定义起使请求前缀缓存失效。已有调用和结果历史继续按追加方式保留。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 个人配置不跨设备同步。同源保护不能代替远端 MCP 自身认证；远端仍须在其他入口执行数据权限校验。删除连接器不会擦除已有会话正文。

查询返回 `MCP_DATA_FORBIDDEN` 时保留已授权工具，同一会话可以立即查询允许的楼层。连接器权限撤销及身份过期仍清除工具注册。工具说明要求模型直接返回有权限的楼层数据，说明其他楼层无法获取，不要求用户扩权或新建会话。
