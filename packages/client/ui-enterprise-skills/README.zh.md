# @deepseek-ai/dsh-client-ui-enterprise-skills

[English](README.md) | 中文

## 概述

员工可以使用获授权的企业技能，通过 ZIP 导入、对话确认创建和修改，以及卸载管理个人技能。企业包独立缓存。管理员只接收个人技能元数据，正文及附件保留在本机。

输入框技能选择器将所选内容追加到当前会话但不自动发送，并保留草稿与附件。管理页面的使用按钮开启新会话。

## 使用本包

页面固定标题、页签和搜索栏，技能卡片在下方剩余区域内滚动。

输入菜单隐藏手动 `/compact` 入口；会话预设仍启用自动上下文压缩。直接输入 `/compact` 仍可使用。

随附桌面组合通过 connection、enterpriseConnection、skills 和 tools 挂载本插件。部署显式配置 dataDirectory、maxArchiveBytes、maxUnpackedBytes、maxFiles 和 refreshIntervalMs；当前分别限制 ZIP 32MiB、解压 64MiB、20,000 项，目录周期为 30 秒。

卡片采用固定高度和两行简介，完整说明在弹窗内部滚动。企业图标优先使用管理员上传的 PNG/JPG，缺失或无法读取时保留默认图标。对话修改为所选个人技能打开新会话，详情弹窗还提供卸载操作。

<a id="understand-the-implementation"></a>
## 实现说明

管理页面首轮以 `summary=1` 获取无图标技能摘要，先显示列表；随后以 `wait=1&display=1` 后台读取 `employee/skill-catalog?icons=1`，补齐图标和技能包就绪状态。不读取模型、连接器、专家或通知，图标请求不阻塞首屏。输入框和专家技能解析请求（`wait=1`）读取不含图标和无关资源的轻量技能目录，只等待企业技能包。加载技能时仍向服务端检查当前授权。

独立的 ./archive 导出校验 ZIP 结构、安全路径、元数据和调用标志，不启动插件；企业服务复用同一实现。唯一最外层的 SKILL.md 定义主技能，其目录内的子技能指南和相对资源原样保留。拒绝并列主入口及主目录之外的文件；支持外层包装目录，导入不执行脚本。

企业下载校验 SHA-256，按员工、资源和摘要分别缓存，实际读取重新检查授权。新版本及回滚版本使用各自目录，保留运行任务引用的旧资源；准备技能包不阻塞初次目录返回。

技能提供者、个人技能操作及后台准备读取 `employee/skill-catalog`，获取当前授权与元数据，不下载图标、模型目录或连接器。仅技能中心展示使用技能目录的 `icons=1` 选项读取卡片图标。更新客户端前须先部署轻量目录接口；权限检查保持实时，失败时停止依赖该检查的操作。

个人技能位于 dataDirectory 下按员工摘要划分的目录。确认后的对话修改原子替换 SKILL.md，保留资源、启停状态、调用设置和额外元数据，数字版本自动递增；替换 ZIP 需明确确认并提交当前摘要，过期摘要返回冲突。卸载先移出可见目录再清理，清理失败记录日志。

个人技能缺少版本时按 1.0.0 读取，兼容 2.3 等数字版本；lfclaw-enabled 缺失时为启用。停用技能不进入新目录，后续读取被拒绝。损坏定义单独标记，不影响其他技能，且仍可卸载。

Host 使用保存在 .device-id 的随机设备标识，上报名称、简介、版本、个人来源和启停状态。导入、修改和卸载后提交完整快照，覆盖该员工/设备清单并周期重试；服务器校验员工身份并拒绝额外技能字段，不上传正文、脚本、附件及路径。

<a id="model-experience"></a>
## 模型体验

### 技能与个人编辑

#### 模型看到什么

save_personal_skill 仅在用户要求创建并确认内容后保存。read_personal_skill 读取现有定义与修订摘要；update_personal_skill 在用户确认修改内容后更新原技能，并拒绝过期摘要。各调用进入标准工具日志。个人调用名以 my- 开头，企业调用名带稳定资源后缀。开始使用在输入框插入显示原始技能名称的引用标签；唯一调用标识保存在草稿中，发送时展开为开头的 /名称，由 tool-skill 确定性注入正文，也支持仅限用户调用的技能。用户和模型调用开关保持独立。 企业和个人技能提供者随已加载定义返回原始展示名称。Host 在显式调用时记录此名称，让已发送消息显示技能名，同时保持唯一加载标识不变。

#### Token 影响

加载的技能正文、个人编辑工具参数和工具结果占用请求上下文。技能加载由 `tool-skill` 记录；未加载的个人附件不进入模型请求。

#### KV Cache 影响

加载技能或读取修改后的定义会向会话追加内容；保存不会重写已记录的指令。启停技能改变后续目录，可能使缓存从首个变化处失效。

## 已知限制与待完成工作

<a id="known-limitations-and-deferred-work"></a>

- 个人正文不跨设备同步；离线设备的后台元数据可能过时。上报失败不撤销本机保存，Host 会记录待同步警告并重试。
- 停用、卸载或撤权不擦除已写入会话的指令。
- 企业缓存保留旧版本以保护运行任务，本包不自动清理历史缓存。
