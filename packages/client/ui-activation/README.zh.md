# @deepseek-ai/dsh-client-ui-activation

[English](README.md) | 中文

## 概述

员工使用激活码登录桌面端，查看授权模型并通过企业网关发送请求。员工令牌留在 Host，企业模型密钥留在服务器。目录及调用检查当前权限；断网时保留凭据以便重试。输出达到上限时可进行有次数限制的自动续接。

## 使用与授权

Host 为 `employee/me`、专家目录与连接器目录各保留一份当前员工的内存快照，后台同步响应更新快照。仅目录展示调用可显式通过 `catalogMaxAgeMs` 复用近期响应；默认请求、权限检查与工具执行始终访问企业服务。换账号、退出、同步失败及连接器账号修改清除相关快照；过期后重新请求，延迟返回的旧请求不会覆盖较新的结果。

桌面 profile 使用员工激活码连接企业服务，Host 将服务地址和令牌保存到 credentials 存储；渲染层仅接收验证状态及员工名称，不保存令牌。每次打开工作区重新调用企业员工接口，失效或离线时不进入界面。离线不删除本机凭据，服务恢复后可重试。

`serverUrl` 是包含 `/lfclaw/api` 的企业接口根地址，`timeoutMs` 为请求超时。桌面配置默认指向正式服务 `http://8.216.38.213:39811/lfclaw/api`，本地运行和人工联调也使用该地址。`allowInsecureHttp` 默认为 false；正式 HTTP 部署的随附配置显式设为 true，仍拒绝包含用户名、密码、查询参数或片段的地址。`LFCLAW_SERVER_URL` 可用于经用户要求的地址调整；切换服务器后重新激活，不把旧令牌发送到新地址，也不迁移或删除本机聊天数据。

桌面模型目录只展示员工授权的 OpenAI 兼容文本模型，并使用服务端默认模型；已选模型仍有效时保留个人选择。每次模型调用前重新读取授权，后台每隔 `refreshIntervalMs` 刷新目录。企业提供商密钥仅保存在服务器，桌面 Host 使用员工令牌访问企业网关。企业技能、连接器及专家由各自客户端插件接入。

模型发现、选择及请求准备读取 `employee/model-catalog`，仅返回已授权模型的元数据，不下载技能图标或连接器目录。更新客户端前须先部署提供此接口的服务端；接口不可用时报告目录加载失败，不回退到完整员工响应。

企业服务连接中断时，模型请求报告可重试的 `TRANSPORT` 错误，并提示先检查工作区中可能已经写成的文件；失败不会自动删除已有文件。

激活页采用白色欢迎界面、LFClaw 文字品牌与轨道图形；小窗口允许页面内滚动，输入区域保持可见。图形只作装饰，键盘焦点限制在激活对话框内；字段和提示文案由中英文词典提供。

激活验证成功后，侧栏底部展示员工姓名与部门名称；收起侧栏只显示姓名首字头像。展示资料来自企业员工接口，激活码和令牌不进入员工信息组件。部门未配置时显示“未分配部门”。

点击侧栏底部员工信息可选择“退出并重新激活”。确认后清除本机员工凭据，重新加载客户端并返回激活页，可输入相同或其他员工的激活码；本机聊天记录和文件保留，不按员工账号隔离。退出不撤销其他设备的登录，也不等待正在运行的任务结束，后续企业请求可能因凭据缺失而失败。退出响应失败或结果无法确认时，弹窗保留并提示重试或重新打开客户端检查状态。

模型适配使用现有 PiAiAdapter；每个模型的 `contextWindow` 与 `maxTokens` 由管理端授权目录提供，修改后在刷新目录及下一次请求准备时生效；桌面部署值仅用于尚未返回容量字段的旧服务器。非法容量会清空目录并报错。网关实时转发上游 SSE，保留文本、思考和工具调用分片，完成后记录用量；上游返回普通 JSON 时兼容转换为 SSE。停用员工、撤销模型授权或重置激活码会阻止后续模型请求。

企业模型保留技能、命令及连接器所需的工具定义、上下文和调用结果。应用不设置 LFClaw 助手身份，也不指定模型自报名称；实际调用型号以请求记录和上游响应为准。

部署显式配置 `modelMaxRetries` 控制企业模型最多重试次数，当前桌面设为 1；`timeoutMs` 当前为 150 秒，长于企业网关 `modelTimeoutMs` 的 120 秒。上游超时与断流按失败显示，不能将已经中断的输出报告为完整结果。

激活页使用应用的 `./assets/lfclaw-logo.svg` 透明金色品牌图标。

本机 `GET /api/lfclaw/branding` 从部署指定的企业服务读取公开首页文案，只返回口号、标签及显示开关，不携带员工令牌。请求使用 `timeoutMs` 并禁止重定向；失败返回非成功状态，由欢迎页显示重试入口。

首页文案注册到 `conversation.hero.brand.text`，从本机 `/api/lfclaw/branding` 读取。首页挂载及窗口重新获得焦点时刷新；失败保留上次文案并显示重试入口，首次加载前使用词典中的默认口号。配置由管理端维护，仅用于界面展示，不进入模型请求。 此注册随企业激活插件装载，不依赖默认停用的专家页面插件。

企业模型输出达到上限时，Host 在同一 Session 排入带 notice 来源的下一轮续接，保留截断前的文本和已完成的工具结果。每个人工请求最多自动续接 `maxAutoContinuations` 次（部署值 3，设为 0 可关闭）；连续 `maxNoProgressContinuations` 次（部署值 2）空文本或与前一轮相同的文本且没有成功工具结果时，报告停止原因。接口失败沿用 `modelMaxRetries`，不会触发输出续接。用户排队的新消息优先，取消和插件卸载撤回尚未执行的自动提示。续接次数随提示持久化，恢复后仍受次数上限约束；不会仅因打开历史记录自动请求模型。不同措辞的无效输出不保证被识别，最大次数仍限制请求总量。

应用组合显式启用 compaction-basic，自动压缩阈值为上下文的 80%，并为输出与 4096 token 余量预留空间；保留近期约 16% 的可用消息预算，摘要上限 4096 token。摘要保留用户目标、关键事实、文件、当前工作、待办事项和下一步，原始会话记录仍保留。压缩摘要与上下文超限恢复各最多重试一次，持续失败最终通过请求错误报告。

企业请求在发送前按最新授权容量估算消息、系统提示和工具定义，并预留输出预算。估算超出窗口时报告上下文超限，交由现有压缩恢复流程处理；无法压缩到预算内时停止，不发送已知超预算请求，也不触发输出自动续接。估算不是提供商的精确分词结果。

<a id="model-experience"></a>
## 模型体验

### 自动输出续接

#### 模型看到什么

自动续接指令进入模型上下文并写入会话日志。续接提示要求从中断处继续，不重复已有内容和已完成的工具操作；历史压缩保留任务摘要和近期消息。

#### Token 影响

每次续接增加一条 notice 提示及其后续输出。已完成的工具结果保留在历史中；压缩由组合中的 compaction-basic 负责，原始日志仍然保留。

#### KV Cache 影响

续接追加消息，不改写已完成的输出。上下文压缩会替换请求中的历史表示，缓存复用取决于首个变化位置。

## 已知限制与待完成工作

<a id="known-limitations-and-deferred-work"></a>

- 自动续接无法保证任务一定完成，也无法完全识别换一种措辞的重复输出；次数上限仍然生效。历史压缩不保证逐字记忆全部对话。真实模型调用、部署后的运行和安装器交付需要分别验证。

<a id="dev-note"></a>
### 开发备注

自动续接通过现有 agent 事件和持久化 inbox 工作，接口失败由模型适配器的有限重试处理。持久化兼容说明见[续接消息来源记录](../../../docs/persistence-changes/2026-10-16-lfclaw-output-continuation.zh.md)。
