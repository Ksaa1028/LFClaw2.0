The [implementation plan](implementation-plan.md) records delivery order and acceptance criteria. Conflicts follow the latest user confirmation and [product and implementation baseline](../06-架构设计/产品与实施基线.md). Planned approval, billing or quota features must not be added to current scope automatically.

## Acceptance criteria

<a id="验收规则"></a>

- The UI uses its intended runtime or backend data source.
- Loading, failure and unknown outcomes are visible; mock data does not represent production data.
- The [contributor log](../07-工作日志/贡献者记录.md) records executed checks and remaining issues.

See the [architecture directory](../06-架构设计/README.md) for design and the [work log](../07-工作日志/README.md) for validation evidence.
