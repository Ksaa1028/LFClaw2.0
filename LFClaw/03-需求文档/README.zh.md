## 产品范围

<a id="产品范围"></a>

员工端面向 Windows x64 与 macOS Apple Silicon，使用激活码进入企业工作环境。管理端为管理员 Web 应用。企业集中授权资源，员工可管理允许的个人扩展；聊天、工作文件和定时任务优先在员工本机运行。

阅读顺序：产品需求、原始提取文本、对应设计图，再对照[产品与实施基线](../06-架构设计/产品与实施基线.md)。
