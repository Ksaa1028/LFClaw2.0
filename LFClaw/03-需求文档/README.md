## Product scope

<a id="产品范围"></a>

The employee desktop targets Windows x64 and macOS Apple Silicon, using activation codes to enter the enterprise environment. Administration uses a Web application. Enterprises centrally authorize resources while employees manage permitted personal extensions; chats, work files and scheduled execution primarily run locally.

Read the product requirements, extracted baseline and relevant designs, then compare the [product and implementation baseline](../06-架构设计/产品与实施基线.md).
