# LFClaw 产品需求文档（PRD）

## 1. 项目信息

| 字段 | 内容 |
|------|------|
| 语言 | 中文 |
| 编程语言 / 技术栈 | Vite + React + MUI + Tailwind CSS（桌面端基于 Electron，管理后台为 Web） |
| 项目名 | lfclaw |
| 原始需求 | 基于 DeepSeek Harness（DSH）构建面向商场企业员工的企业级 AI 桌面工作平台，包含「员工客户端」与「管理员后台」两个独立前端产品；支持激活码登录、部门/员工管理、模型网关、技能/连接器/专家分发、插件管理、定时任务、会话分享、消息通知、客户端更新与系统管理等 16 项业务模块（功能 14 取消，功能 10 暂不实现）。 |

---

## 2. 产品目标与边界

### 2.1 产品目标

1. **开箱即用的企业 AI 工作入口**：员工安装客户端后仅需输入激活码即可进入聊天，无需配置服务器地址或企业 API Key，降低企业推广门槛。
2. **企业资源统一管控、个人扩展自由并存**：管理员通过后台统一发布模型、技能、连接器、专家和插件；员工可自主创建个人技能、专家、插件并绑定个人 IM，二者在界面与权限上清晰隔离。
3. **安全可控的本地优先体验**：聊天、工作文件、定时任务、IM Agent 优先在员工本地运行；企业核心数据权限由服务端校验，客户端不暴露企业 API Key。

### 2.2 产品边界

| 范围 | 边界说明 |
|------|----------|
| 客户端平台 | 仅 Windows x64 与 macOS Apple Silicon；不做 Intel Mac、Linux。 |
| 管理员后台 | 仅 1 个超级管理员账号，复用既有 LFClaw 后端；不引入复杂 RBAC。 |
| 数据同步 | 本地聊天/工作文件不自动跨设备同步；个人专家配置跨设备同步；个人技能/插件不跨设备同步。 |
| 知识库 | 不自研知识库引擎，不开发个人长期记忆；功能 10 权限方案待核查后再接入。 |
| 服务器 Agent | IM 消息处理与定时任务不在企业服务器运行；员工电脑关闭则相应能力不可用。 |
| 故障诊断 | 不开发独立故障诊断模块，仅保留 DSH 原生错误提示与基础日志。 |
| 发布更新 | 面向全员发布，不做灰度/分批/按部门推送；Win/Mac 独立版本号与安装包。 |

## 3. 用户故事

### 员工角色

1. **作为新员工**，我想要首次打开客户端后只输入激活码就能登录，这样我就不需要填写服务器地址或企业 API Key。
2. **作为普通员工**，我想要在聊天输入框里切换已获授权的模型，这样我就能根据任务需要选择合适的企业模型，同时不会看到未授权的模型。
3. **作为业务人员**，我想要使用管理员发布的企业技能和连接器工具，也能自己安装个人插件，这样我既能用企业统一能力又能扩展个人工作流。
4. **作为员工**，我想要把历史会话（含附件和 AI 输出文件）跨部门分享给同事，同事领取后能在自己电脑上独立继续对话，这样我们能快速复用工作成果。
5. **作为员工**，我想要在客户端内收到会话分享、新版本更新和定时任务失败等通知，这样我能及时处理与自己相关的事项。
6. **作为员工**，我想要绑定个人微信 ClawBot 和飞书应用，这样我在电脑运行期间可以通过 IM 私聊让 AI 帮我处理工作。

### 管理员角色

1. **作为超级管理员**，我想要在后台创建部门、添加员工并自动生成激活码，这样新员工才能激活客户端。
2. **作为超级管理员**，我想要按部门或按员工配置模型、技能、连接器、专家的授权，这样企业资源的使用范围可控。
3. **作为超级管理员**，我想要新增/测试企业模型并维护 Base URL、API Key 与计费参数，这样员工只能通过企业网关安全调用模型。
4. **作为超级管理员**，我想要上传 ZIP 格式的企业技能并解析 SKILL.md，这样我能管理技能的版本、回滚和授权。
5. **作为超级管理员**，我想要发布 Windows 与 macOS 客户端安装包到 OSS，并设置普通/强制更新，这样员工能自动获取新版本。
6. **作为超级管理员**，我想要查看平台用量、费用、系统状态和操作日志，并能手动备份与恢复数据，这样我能掌握企业运行状况并降低数据丢失风险。

## 6. 核心交互流程

### 6.1 激活码登录

1. 员工首次打开客户端，进入「激活码登录页」。
2. 输入形如 `LF-NAME-XXXXXXXX` 的激活码，点击登录。
3. 客户端向企业后端发起身份验证，成功后返回登录凭证并本地保存。
4. 后续启动自动联网校验账号状态：
   - 账号正常：进入首页聊天。
   - 账号停用：禁止访问，提示联系管理员。
   - 账号重新启用：已登录设备自动恢复，无需重新输入激活码。
   - 激活码被重置：旧凭证失效，所有设备需重新输入新激活码。
5. 员工在当前设备退出登录仅影响该设备。

### 6.2 模型切换

1. 员工在首页聊天输入框内点击模型下拉。
2. 列表仅展示企业已授权模型，当前默认模型置顶或高亮。
3. 选择模型后，后续对话请求经 LFClaw 模型网关转发，网关校验员工授权、托管企业 API Key。
4. 个人插件自行调用第三方 AI 服务时，不经过企业网关，不计入企业费用。

### 6.3 技能/连接器/专家使用

1. 员工进入对应页面，默认展示「企业」资源 Tab。
2. 企业资源由后台自动同步，员工可直接「试用」/「使用」或在聊天中通过 `@技能名`、`@连接器工具`、`@专家名` 调用。
3. 切换到「我的」Tab，员工可创建、编辑、删除个人资源；企业资源与个人资源同名时以来源标签区分。
4. 连接器工具级权限在后台配置，客户端仅展示已授权工具；个人账号绑定后才可使用需要个人凭据的工具。

### 6.4 会话分享领取

1. 发送人在历史会话中选择完整聊天记录（含原始附件和 AI 输出文件）。
2. 选择接收人（支持按员工检索、多选、跨部门），确认分享。
3. 后端将分享数据临时存于本地磁盘，默认 30 天有效、单份总量上限 50MB。
4. 接收人客户端消息中心收到分享通知，进入「会话分享 → 收到的分享」查看。
5. 接收人点击「继续对话」，分享内容在本地生成独立 DSH 新会话，原始内容与新增内容区分展示。
6. 分享过期后不可再次领取，但本地已保存的会话可继续对话。

### 6.5 定时任务创建

1. 员工进入「自动化任务」，点击「新建任务」。
2. 填写任务名称、触发规则（时间表达式或自然语言）、执行指令/关联会话。
3. 任务保存在本地，仅当客户端及 Host 运行期间执行。
4. 任务列表展示运行状态、下次运行时间、最新结果；失败时在客户端消息中心通知。
5. 管理员后台只读查看任务元数据快照，不看指令、结果或聊天记录。

### 6.6 后台授权流程

1. 管理员在「部门管理」维护组织结构。
2. 在「员工与激活码」新增员工，系统自动生成激活码；可单独为员工增删授权。
3. 在「模型/技能/连接器/专家」管理页面创建企业资源，并配置授权范围（全员/部门/员工）。
4. 员工的有效授权 = 部门继承 + 个人覆盖；界面需展示授权来源。
5. 授权变更后，服务端立即校验，在线客户端自动刷新；正在进行中的任务不中断，新请求按最新权限处理。

## 7. UI 设计稿说明

### 7.1 设计语言

- **风格**：简洁、现代、企业级；参考 DeepSeek Harness 桌面应用风格。
- **配色**：
  - 主背景：白色 / 浅灰（`#F5F6F8`）。
  - 主色：蓝色（用于激活态、按钮、链接）。
  - 辅助色：紫色（模型/专家）、绿色（成功/启用）、橙色（技能/通知）、红色（失败/停用）。
  - 文字：深灰标题 + 中灰正文。
- **字体**：系统默认无衬线字体，中文优先使用 PingFang SC / Microsoft YaHei。
- **图标**：线性图标，左侧导航与卡片头部使用彩色面性图标增强识别。

### 7.2 客户端布局

- **左侧固定导航栏**（约 220px）：
  - 顶部 Logo +「新会话」大按钮。
  - 中部主导航：首页、账号、技能、连接器、专家、会话分享、自动化任务、插件。
  - 下部会话历史区（可折叠）+ 用户头像名片。
- **右侧主内容区**：
  - 顶部窄标题栏显示当前页面名称与全局操作（如新建、搜索、筛选）。
  - 下方内容区分块展示卡片或列表。
- **首页特殊布局**：
  - 中央欢迎区 + LFClaw 图标 + 快捷能力入口卡片。
  - 底部聊天输入框居中，左侧附件、右侧模型选择与发送按钮。
  - 输入框下方展示最近会话。

### 7.3 管理后台布局

- **左侧深色导航栏**（约 240px）：
  - 顶部「LFClaw 企业管理」Logo。
  - 导航项按业务模块垂直排列，当前项高亮。
- **顶部栏**：管理员 Token/名称、退出按钮。
- **主内容区**：
  - 页面标题 + 描述 + 全局操作按钮（新增、上传、立即备份等）。
  - 统计卡片行 + 列表/表格/图表。
  - 详情采用右侧抽屉或弹窗，避免打断列表上下文。
