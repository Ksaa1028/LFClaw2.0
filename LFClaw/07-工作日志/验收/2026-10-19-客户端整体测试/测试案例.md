# 2026-10-19 员工客户端整体测试案例与执行记录

## 范围和判定

本案例覆盖员工桌面端、企业服务和本地数据的主要交互。管理 Web 只作为准备员工、资源及授权的入口。每一步同时检查页面结果、服务端响应或持久数据，以及越权和失败路径。当前执行记录只代表 2026-10-19 本机源码与恢复数据目录，不代表 Windows 安装包或 macOS 安装包的发布验收。

状态含义：`通过`表示本次观察到指定结果；`失败`表示本次检查未满足断言；`待实测`表示已列入案例但本次没有完成产品运行操作。单元测试通过不替代桌面交互通过。

## 测试环境与数据

- 员工页面入口：本机 DSH Web `http://127.0.0.1:39811/`；管理 Web `http://127.0.0.1:5173/`。两者均返回页面，员工页面实际显示激活码输入框。
- 企业服务：`/lfclaw/api`；当前 `LFCLAW_DATA_DIR` 为 `LFClaw/02-管理端/server/data/recovery-2026-10-19/`。这是从 2026-10-14 备份恢复的独立目录；原 `data/live/db.json` 无效，未对其读写或清理。
- 恢复目录本次读取到 1 名有效员工、1 个模型、1 个技能、1 个连接器、3 个个人专家、0 个企业专家。测试只读取现有业务资源；激活调用会新增员工会话。文档不记录激活码、令牌、模型密钥或聊天正文。
- 完整写操作案例须另建临时数据目录，至少准备管理员、同部门员工 A、跨部门员工 B、两个设备数据目录，以及可控的模型和 MCP 测试端点。完成后核对独立目录中的数据库、技能 ZIP、分享文件和会话文件。

## 一条完整业务案例

| 步骤 | 员工端操作 | 服务端与本地核对 | 异常分支 |
|---|---|---|---|
| 1 | 用员工 A 激活码进入，关闭并重启客户端 | `/employee/me` 返回 A 的身份和当前生效资源；设备 Host 保存凭据，浏览器不持有企业密钥 | 错码拒绝；停用拒绝，重新启用后原登录恢复；重置激活码使旧会话失效；本机退出不影响另一设备 |
| 2 | 在输入框选择授权模型，发送一轮含文件的对话并继续第二轮 | 模型 ID 对应管理员配置；服务端记录请求与 Token 用量，本机会话和附件可重开；企业 API Key 不出现在员工响应 | 撤权或停用后新请求拒绝；超时、断流和取消可见，失败请求不能伪装完成；费用未知显示“未获取” |
| 3 | 查看企业技能并调用，再查看个人技能 | 下载 ZIP 的 SHA-256 与员工目录一致；企业版本更新或回滚后同步到本机，个人技能内容不上传管理员 | 非法 ZIP 拒绝；撤权不能继续下载；同名企业与个人技能可区分；同步失败保留可恢复状态 |
| 4 | 查看授权连接器和工具，调用商场 MCP | 客户端目录只列当前授权工具；服务端按员工楼层、工具授权逐次限制结果 | 无楼层权限拒绝；部分楼层不返回全场数据；请求中撤权丢弃旧结果；个人连接器不能同源绕过商场网关 |
| 5 | 创建、修改、调用个人专家和专家团 | 本人多设备可读配置；发送的会话记录包含本次使用的配置；专家团必须有真实子代理调用及结果 | 他人不能读写；依赖撤权或成员缺失时不可准备；修订冲突不覆盖新配置；管理员不见私人内容 |
| 6 | 新建、重命名、归档并恢复会话，查看文件和输出 | 本机持久化内容重开后保持一致，服务端不采集普通聊天正文 | 损坏会话显式报错；失败操作不清空原记录；删除和恢复按产品实际语义核对 |
| 7 | 将完整会话及附件分享给 B，B 领取并继续 | 服务端分享副本含附件和输出；B 本机创建独立继承会话，A 原会话不变，后续工具调用按 B 的授权 | 超限和缺文件拒绝发送；未指定收件人不可下载；过期阻止领取；已领取的本地文件不因过期丢失 |
| 8 | 建立本地定时任务，查看通知、插件和账号页 | 任务只在本机 Host 运行；服务端管理员仅见允许上报的任务及个人插件元数据；账号页资源与 `/employee/me` 一致 | 客户端关闭时不承诺运行；网络中断显示同步失败；企业插件更新不覆盖个人配置 |
| 9 | 检查客户端更新并重启 | Windows 与 macOS 使用各自版本；更新前后本机会话、文件、设置一致 | 强更阻止旧版本继续使用；下载或安装失败可恢复；未签名或校验失败的包拒绝安装 |
