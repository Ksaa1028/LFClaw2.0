# 2026-10-21 模型用量报表

## 目标

管理端按员工账号和企业模型查看 Token 使用量，并控制新增报表对员工模型调用的影响。

## 实际修改

- 管理端新增“模型用量”页面，按 UTC 日期、员工和模型筛选；展示账号与模型两张分页汇总表、调用次数、已获取的输入/输出/总 Token 及缺失用量次数。
- 服务端新增仅管理员可读的 `/api/admin/usage` 汇总接口，查询时扫描已有模型网关用量记录，不接入员工调用流程。删除员工或模型后的历史记录显示 ID。
- 管理端初始数据不再传输逐次 `modelUsage`；总览本月费用在服务端按原口径汇总返回。服务端仍使用单个 JSON 数据文件，同步读取和扫描可能在大量记录时影响同进程请求，尚未做容量基准。
- 补充接口、汇总、日期校验、权限和页面筛选测试，并更新管理端与服务端说明。
