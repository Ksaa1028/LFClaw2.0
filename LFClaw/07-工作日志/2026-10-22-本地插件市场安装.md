# 本地插件市场安装

按用户要求试装 dshmarket。本地 LFClaw 使用开发数据目录下的 desktop Profile；普通源码 CLI 拒绝管理该专用 Profile，改用现有 Windows 产物携带的 Desktop CLI，在关闭本地客户端后执行 plugin --profile desktop add dshmarket。

命令退出码为 0，实际安装版本为 1.66.45，已登记到开发 Profile 的依赖和 bundle 列表。安装存在 peer dependency 警告，未设置版本兼容豁免。重启本地客户端后，实测“设置 → 插件市场”页面能打开并加载插件列表；没有进一步安装市场中的插件。此次仅安装到本机开发 Profile，未修改分发安装包的默认依赖或发布新版。

用户随后要求移除插件市场。通过同一 Desktop CLI 执行 `plugin --profile desktop remove dshmarket`，退出码为 0，已确认开发 Profile 的依赖和 bundle 列表均移除 dshmarket，并重新启动本地客户端。
