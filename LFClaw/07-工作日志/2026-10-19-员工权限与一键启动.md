# 2026-10-19 员工权限与一键启动

## 修改

商场 MCP 权限只读取员工个人多选，不再从所属或上级部门继承。一至四层与营运自营可任意组合，空配置、缺失或无效配置均无权限，已有个人配置保留。部门表单移除楼层和自营，员工详情移除继承单选，接口拒绝 null 并不再返回 mode。

根目录新增一键启动LFClaw.bat，调用构建运行目录的 PowerShell 脚本，通过支持的 dsh profile 启动企业 API 并启动管理 Vite、桌面。脚本检查依赖、已有数据、端口和健康状态，复用已有进程，输出地址和日志，互斥锁防止同时启动；不重置凭据，不自动创建空库。正式部署仍采用版本归档流程。
