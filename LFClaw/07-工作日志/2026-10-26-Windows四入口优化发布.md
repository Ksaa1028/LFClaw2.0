# Windows 四入口优化发布

## 范围

按用户要求发布 Windows x64 客户端，macOS 等待 Windows 验收后另行安排。本次包含消息与模型切换性能修复、已有会话中的引用选择修复，以及技能、连接器、专家和专家团输入框目录优化；功能实测见同日四入口优化记录。

## 构建与检查

首次版本 2026102603 在客户端类型检查阶段失败，未产生交付包、未上传。新增连接器 Host 测试误命名为 picker-host.spec.ts，导致客户端聚合程序引入 Host 类型；改为约定的 picker.host.spec.ts 后，pnpm exec tsc -b tsconfig.client.json 通过。失败编号保留，正式构建改用 2026102604，对应版本 2026.10.26-4。

连接器 picker.host、桌面 lfclaw-update-signature、lfclaw-update-config、update-coordinator 四个文件共 29 项测试通过；发布目录保留规则 2 项通过。正式打包通过根目录一键 Windows 脚本执行，不跳过源码构建或产物界面检查。
