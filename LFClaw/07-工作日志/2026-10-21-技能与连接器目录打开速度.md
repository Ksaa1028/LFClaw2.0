# 技能与连接器目录打开速度

## 范围

输入框加号下的技能与连接器选择器、技能管理、工具连接。服务地址保持 `http://8.216.38.213:39811/lfclaw/api`，本次仅更新本地桌面客户端，未更新生产服务或发布安装器。

## 实现

企业连接服务按当前员工保留员工目录和连接器目录各一份内存快照。后台同步更新快照，展示请求按现有 `refreshIntervalMs` 复用，默认请求仍访问服务器。身份变更、注销、同步失败及连接器账号修改使相关快照失效；请求顺序和代次防止旧响应覆盖新状态。企业目录版本监听仍访问服务器，加载技能及调用工具仍实时鉴权。

连接器选择器并行请求企业和个人目录。技能选择器只等待当前技能包的准备任务，不等待个人技能清单上报。页面手动刷新请求服务器最新数据。

## 实测

通过运行中 Electron 的本机 BFF 获取目录并解析 JSON，包含本机协议、Host 和需要时的生产网络耗时，不包含点击、React 渲染与屏幕绘制。每个接口连续采样三次；改动前技能数为 3，改动后为 4，连接器分别为企业 2、个人 0。

| 路径 | 改动前 ms | 改动后 ms |
| --- | --- | --- |
| skill-center | 842 / 777 / 756 | 72 / 73 / 63 |
| skill-center?wait=1 | 753 / 757 / 857 | 63 / 72 / 69 |
| connector-center | 466 / 458 / 456 | 40 / 38 / 51 |
| personal-connectors | 799 / 801 / 787 | 15 / 15 / 15 |

手动刷新复测：技能 1263 ms，之后普通读取 69 ms；企业连接器 403 ms，之后普通读取 37 ms，均 HTTP 200。首次冷启动或快照过期仍可能等待网络。
