# 分支会话删除修复

分支创建入口将 Agent 句柄交给会话控制器保管，删除时先释放句柄再调用持久化删除，避免把 API 创建的分支误判为其他运行组件的会话。保留其他组件所有权及父会话依赖检查。

验证：pnpm exec vitest run packages/api/session-controller/tests/session-fork.host.spec.ts packages/api/session-controller/tests/agent.host.spec.ts，45 项通过。回归覆盖创建分支后立即删除、释放顺序和原会话保留。本次未重新打包桌面应用或执行真实桌面交互。

实际实例复查：目标分支本身仍有普通分叉，父会话依赖检查将普通分叉与任务子会话一并拦截。删除检查仅对 origin: subagent 的任务子会话保留保护，普通分叉拥有独立历史并保留，不阻止删除来源会话。回归覆盖保留普通分叉、拒绝删除含任务子会话的父会话；两组 45 项测试通过，增加拒绝断言后分支组 25 项通过，Host 编译及定向打包通过。

重新构建并重启本地桌面实例后，通过已认证的删除接口删除用户指定的“询问模型身份 (1)”，HTTP 204；确认目标 session.deleted 已写入，原会话和后续普通分支均没有删除标记且保留日志。没有直接改写会话正文或手工删除日志文件。
