# 2026-10-20 连接器通用认证

## 修改

- 管理端支持无认证、API Key / Token、自定义凭据字段和远程 OAuth；账号可由企业共用或员工分别绑定。旧公众号 AppID / AppSecret 配置继续兼容。
- 员工端在未发现工具时也显示账号表单，支持保存凭据、浏览器授权、重新连接及解除连接。非商场发现工具自动可用，商场继续检查工具与楼层权限。
- 企业端复用 MCP SDK 的发现、动态注册、PKCE 和令牌刷新。回调绑定发起者、连接器配置与一次性 state；权限或配置撤回使待完成授权失效，后续恢复权限不恢复旧授权流程。
- 个人远程连接器支持先保存再 OAuth 授权；本机临时回调监听器有到期清理，凭据按员工及配置修订隔离。解除连接或换绑账号后，旧请求不得继续返回数据。
- 通用凭据不在目录或管理数据中回显；表单携带配置摘要，避免把已填写的秘密提交到变更后的目标。私有记录不等同于加密存储，stdio 数据目录隔离不等同于操作系统沙箱。
- 配套说明见[服务端 README](../02-管理端/server/README.md#通用连接器认证)、[客户端 README](../../packages/client/ui-enterprise-connectors/README.zh.md)和[升级指南](../../docs/upgrade-guide/v0.2.1-alpha.2/lfclaw-connector-authentication/guide.zh.md)。

## 部署与限制

先更新员工端再更新企业服务。企业 OAuth 使用 `LFCLAW_OAUTH_CALLBACK_URL`；本机开发默认回环地址，部署到其他机器时必须改为员工浏览器可达的 HTTPS 回调地址。个人连接器使用员工本机回调。预注册 OAuth 目前支持公开 Client ID；要求专用认证流程或机密客户端的服务需要另行适配。本地解除连接不会撤回服务商网站上的授权同意。
