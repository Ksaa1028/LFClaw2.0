# 2026-10-20 企业连接器 stdio 支持

## 修改

用户要求在企业管理端增加 stdio 配置，支持此前提供的 `npx`、`args`、`env` 连接器。传输选择新增“stdio（本地命令）”，选择后展示启动命令、参数 JSON 数组和环境变量 JSON 对象，远程模式保留地址与 Header。中英文文案说明命令和数据路径属于企业服务器。

企业服务使用 MCP SDK 的 stdio transport，保存校验、管理员测试、员工工具发现和调用均接通。环境变量读回置空，命令和参数未变时留空保留原值，改动后必须重新填写；切换传输清除另一种传输的配置。管理员操作日志只记录修改项名称。stdio 只继承 SDK 的基础环境变量白名单并合并管理员输入，stderr 不进入企业日志。

员工沿用连接器、工具和商场楼层授权检查；配置或权限变化继续中断正在执行的调用并丢弃旧结果。每次操作独立启动进程，结束和超时关闭连接，关闭逻辑复用同一个 Promise，等待已经开始的中断清理。Java MCP 代码和配置均未修改。
