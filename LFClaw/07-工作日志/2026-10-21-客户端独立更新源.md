# 客户端独立更新源

用户要求上传后旧版识别新版本并由用户选择更新，同时停用 DeepSeek Harness 原更新源。已安装的早期未签名包没有 `app-update.yml`，不能通过服务器上传补上客户端代码；这批包必须手动覆盖安装一次带更新能力的版本。不得把该限制表述为上传后旧包就能自动提示。

LFClaw 一键入口内置专用更新地址，electron-builder 生成对应 `app-update.yml` 并在应用元数据中内置 Ed25519 公钥，省略原强制更新策略。普通非 LFClaw 构建的原配置不改。客户端更新协调器在展示可用版本前核验签名；版本、文件名、大小和 SHA-512 任一改变均拒绝，清除未可信候选。下载使用全量包，用户另行确认安装。更新签名不是 Windows Authenticode 签名；安装器仍未签名。

维护者本机生成独立发布密钥，私钥保存在用户目录而非仓库、服务器或产物。发布工具生成单文件归档、签名清单和哈希清单；服务器部署器校验条目、大小、哈希、签名及递增版本，先放不可变安装器再原子替换清单。管理端 `2026102103` 已上传并启用，健康返回该编号及 ready；原业务数据和配置保留。新静态接口的缓存与 Range、私有路径隔离、重启后业务记录和令牌保留均在本地真实归档测试通过。

签名与更新协调器二十四个案例通过。`2026102109` 完整构建末尾的插件安装检查因 Windows 临时目录重命名 EPERM 中断，未复制交付；使用新隔离目录重跑相同运行检查通过。界面检查曾因 Playwright 不支持回调内动态 import 而报测试工具错误，改用 Node 内置模块读取 API 后通过。没有跳过对应断言。真实包显示 `2026.10.21-9`，品牌、渠道入口、原生版本、LFClaw 更新源、公钥及原策略缺席均已检查。

为了让用户自行验证更新，保留 `2026.10.21-9` 作为首次安装版，以相同已验证运行时重新封装递增的 `2026.10.21-10`。后者仍须运行实际产物检查，不将前者结果直接视为通过。服务器将保留两个不可变安装包；先安装前者后再由客户端选择更新。实际上传结果和下载验证在完成后补记。

发布操作与密钥保管见[客户端更新发布](../08-构建运行/desktop-release/README.md)。安装升级是否保持真实用户会话仍需用户在本机完成覆盖安装验证；自动资格检查不执行安装器，不覆盖用户现有程序。

两个版本的真实界面及打包运行检查均通过，服务器均完成 SHA256 核对、归档内容与签名验证。线上清单为 `2026.10.21-10`，两个安装包的 HTTP HEAD 均返回 200，大小分别为 291010568 和 291010563 字节。归档 SHA256：`2026102109` 为 `3db0316bb783cc0f9c8e81181ff9b9e78206bcfd9d811cf58947e2e577c2a2d1`，`2026102110` 为 `6c9b6a8383ebac19c76e8af8cf6835dd7cb703d050ac8fa127437046ea86ebd0`。最终签名、协调器与构建环境测试共四十七个案例通过，发布文档中英配对检查通过。

联网资格脚本初次因 Electron 顶层等待 ready 停滞，改为异步入口并增加三分钟超时；随后因测试注入的 NsisUpdater 在创建 provider 后才设置 HTTP executor 而失败，调整为先设置 executor 再创建 provider。生产协调器使用自身默认 updater，未使用此测试注入路径。修改后的检查已发现线上新版并通过签名验证，完整下载结果在完成后补记。

后续检查确认本机 Electron 系统代理为 `127.0.0.1:7897`，代理线路的全量下载较慢；测试时限延长到十五分钟，并增加仅针对隔离测试会话的 `--direct` 参数，不修改用户代理。独立公网下载的完整 291010563 字节与签名清单 SHA-512 相符。直连 Electron 已完成完整下载并报告校验通过，首次在结束前清理数据目录触发 Windows EPERM；改为由父启动器等待 Electron 退出后删除隔离目录，避免把测试清理问题与客户端更新失败混为一谈。

同版本检查确认 `2026.10.21-10` 不重复提示；精确模拟 `2026.10.21-9` 的检查确认会发现 `-10`。额外两项构建配置测试确保只配置 LFClaw 更新路径、公钥存在且原强制更新策略缺席，非法更新路径被拒绝。真实安装器未被执行。

最终父启动器验证退出码为 `0`：模拟 `2026.10.21-9`，从正式服务器发现 `2026.10.21-10`、验证签名、完整下载并由 Electron 校验 SHA-512，退出后清理隔离数据成功。同版本检查也以退出码 `0` 完成。证据分别保存在 `.desktop-build/lfclaw-online-final.log` 与 `.desktop-build/lfclaw-latest-final.log`。安装升级由用户确认执行，测试未代为安装。
