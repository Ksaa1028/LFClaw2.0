## 整理约定

<a id="整理约定"></a>

文件夹使用技能名称；ZIP 使用简短名称，不在文件名中堆叠标识、版本号和语言。每个技能文件夹分别保存技能 ZIP 和图标，不将两者再打包为一个交付文件。

独立图标统一使用 PNG 格式。

新技能使用简短中文文件夹名与 ZIP 文件名，管理端显示名称使用同名。技能包仅将 `SKILL.md` 的 `description` 改为中文，正文、标识、其他元数据、脚本、模板与参考资料保持原样。整理后核对 ZIP 条目及逐文件内容，并按部署容量限制校验完整包。

飞书统一套件 ZIP 保留 `lark-unified/` 顶层目录、内置 Meegle 子技能及包内图标；两个技能入口已中文化。元数据中的图标路径改为包内相对路径，并移除原设备安装时间与已失效的安装内容哈希。ZIP 结构校验通过不代表已完成飞书登录或业务接口验收。

女娲来自 [alchaincyf/nuwa-skill](https://github.com/alchaincyf/nuwa-skill)。上传包经用户确认去除宣传图片、动画和 promo 目录，保留技能正文、脚本、参考资料与全部人物示例，仅重写主入口描述。完整 GitHub 原包与来源、摘要和删减清单保存在 [来源归档/女娲](来源归档/女娲/来源与处理记录.json)；宣传图片的 README 链接可能不再显示。

灵感设计资源已按用户确认完整保留，约 37 MiB，超过当前 32 MiB 上传上限，暂存归档，尚不可直接上传。

七项辅助思考技能来自 LearnPrompt/laoyeye，保留原中文描述和提示语正文，附原始来源许可；调用依赖与使用说明见 [交付说明](来源归档/辅助思考技能/交付说明.md)。
