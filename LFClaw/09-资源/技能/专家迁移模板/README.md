# Expert Migration Template

English | [中文](README.zh.md)

<a id="专家迁移模板"></a>

`SKILL.md` provides a reusable conversational migration process; `专家迁移模板.zip` can be uploaded to the skill center. It converts expert material from other platforms into parameter JSON for preview, listing capabilities not migrated. It never executes source-archive scripts, automatically installs skills or grants connector permissions.

WorkBuddy 1.0 single-expert JSON exports can also be uploaded directly for preview through Import original expert. This template handles other formats, incomplete material and cases requiring manual organization.
