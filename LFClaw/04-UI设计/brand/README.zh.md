# LFClaw 品牌图标

[English](README.md) | 中文

<a id="lfclaw-品牌图标"></a>

界面使用 `lfclaw-logo-transparent.png`，保留金色蟹钳与四角星，背景为透明 alpha。`lfclaw-logo.png` 保留黑底原稿。Web 导出为 `apps/web/public/assets/lfclaw-logo.svg`（内嵌 PNG），桌面和管理端使用对应尺寸的透明导出图。

透明原图由内置 imagegen 编辑生成：移除黑色底板与钳口黑色区域，保留蟹钳、四角星、比例及金色渐变，清理散点与边缘杂色，不添加文字、光晕或阴影。

工作界面图标通过主题样式在浅色模式显示黑色、深色模式显示白色，保留透明通道；启动页、激活页及品牌展示保留金色。管理端侧栏始终为深色，使用白色图标。
