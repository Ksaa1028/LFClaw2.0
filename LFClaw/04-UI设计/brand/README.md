# LFClaw Brand Icons

English | [中文](README.zh.md)

<a id="lfclaw-品牌图标"></a>

The UI uses `lfclaw-logo-transparent.png`, retaining the gold claw and four-point star with transparent alpha. `lfclaw-logo.png` retains the black-background original. The Web export is `apps/web/public/assets/lfclaw-logo.svg` with an embedded PNG; desktop and administration use appropriately sized transparent exports.

The transparent source was edited with built-in imagegen: remove the black backing and black claw opening, retain the claw, star, proportions and gold gradient, clean stray pixels and edge artifacts, and add no text, glow or shadow.

Workspace styling displays black icons in light mode and white icons in dark mode while retaining transparency. Startup, activation and brand presentations remain gold. The administration sidebar stays dark and uses a white icon.
