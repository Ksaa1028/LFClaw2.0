## Interface principles

<a id="界面原则"></a>

The employee app uses left navigation, conversation history and a main workspace; administration uses separate dark navigation and business lists. Keep system sans-serif fonts, clear hierarchy and visible loading and failure states. Implementations reuse DSH components and design tokens; current plugin and administration documentation own exact layouts and interactions.
