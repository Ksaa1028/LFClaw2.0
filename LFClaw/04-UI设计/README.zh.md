## 界面原则

<a id="界面原则"></a>

员工端使用左侧导航、会话历史与右侧工作区；管理端使用独立深色导航和业务列表。保持系统无衬线字体、清晰层级及可见的加载和失败状态。功能实现应复用 DSH 组件与设计令牌，具体布局及交互以当前插件和管理 Web 文档为准。
