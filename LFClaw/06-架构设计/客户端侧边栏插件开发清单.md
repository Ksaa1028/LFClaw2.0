# 客户端侧边栏插件开发清单

本清单按 2026-10-15 用户最新要求与原始需求整理，确定后续开发范围与顺序，不代表功能已实现。客户端是 Electron 桌面应用；企业服务通过 Host 中已保存的员工凭据访问。每完成一个小功能先同步用户验收。

## 一级入口

新建会话保留为主要操作；功能导航按“专家中心、技能中心、连接器、插件中心、定时任务、消息中心”排列，随后是工作区与会话列表。顶部保留设置，底部保留姓名与部门。模型选择继续位于聊天输入框，不新增模型管理页面。

| 入口 | 员工可用功能 | 当前基础与缺口 |
|---|---|---|
| 专家中心 | 企业专家、专家团、我的专家；查看详情、开始对话；文字描述或语音转文字创建个人专家并确认保存；个人配置跨设备同步 | ui-lfclaw 有共享渲染层原型，后端已有企业专家、个人专家草稿与保存能力；需改用桌面 Host 企业凭据，并接通 DSH 专家、专家团与外部专家执行 |
| 技能中心 | 企业技能、我的技能；读取包内描述、查看版本、主动选用；个人技能导入、创建、编辑与删除；企业 ZIP 静默同步、安全更新及回滚同步 | 独立技能中心已接通目录、下载校验、企业/个人隔离、原生加载、个人编辑启停与卸载、后台元数据清单；本轮已补更新通知和失败恢复，真实验收见 2026-10-16 工作日志 |
| 连接器 | 展示已授权连接器与允许的工具、连接状态、必要的个人账号绑定与解绑；企业连接器配置由管理员维护 | 服务端已有授权资源和 MCP 工具接口；需接通桌面工具注册、动态撤权、账号绑定与调用；商场楼层权限必须通过服务端执行，不改 MCP 源码 |
| 插件中心 | 企业插件、我的插件；企业发布与安全更新；个人插件安装、配置、创造模式和卸载 | 复用 ui-plugin-manager 与现有 Cordis 加载机制；需补企业插件发布、授权、分发和企业/个人冲突规则，不能只给现有插件页改标题 |
| 定时任务 | 复用现有任务列表、创建编辑、启停删除、执行记录与回到会话；任务失败进入消息中心 | 复用 ui-schedule 与 DSH 本机调度；补企业模型及资源权限适配、非敏感任务元数据上报和本机失败通知；服务端不代跑任务 |
| 消息中心 | 未读数、分享消息、版本更新、任务失败和本机异常；已读、删除与清空；分享领取后在本机独立继续 | 需建设客户端消息页、按收件人隔离的消息接口、已读状态与保留规则；现有后台通告数据不能视作完整消息系统；不调用系统桌面通知 |

## 配套功能归属

- 账号详情：点击左下角姓名与部门，查看本人账号、有效授权、激活码查看/复制及本机退出；不再增加侧栏账号菜单。
- 会话分享：从会话菜单发起，选择员工并上传完整会话及附件；从消息中心领取，生成独立本地会话；不新增一级分享入口。
- 个人微信与飞书渠道：在顶部设置中提供独立“消息渠道”分组，员工自行绑定；和企业 MCP 数据连接器明确区分。IM 在员工本机执行，不能把普通连接器配置页面视作 IM 已完成。
- 客户端更新：放在设置的关于/更新区域，普通/强更提醒进入消息中心；不额外占用侧栏。
- 知识库：通过获授权连接器或专家使用外部平台；权限方案待确认，不先建设知识库引擎和一级管理页。
- 现有终端、文件、网页、子智能体与团队能力复用 DSH；保留对应任务或插件配置入口，避免全部堆入侧栏。

## 建议开发顺序

1. 技能中心：先接通授权目录、ZIP 描述与版本展示，再完成下载校验、加载、更新与撤权。
2. 连接器：先接通授权目录及工具调用，再验证商场权限与必要的个人绑定；这是专家使用企业数据的基础。
3. 专家中心：先把已有页面接到桌面 Host，再接 DSH 专家、专家团和外部专家；随后完成个人专家创建、依赖提示与运行。
4. 插件中心：复用原生页面补企业发布/分发与个人插件分离；需要同时补企业服务端对应能力。
5. 定时任务：复用调度并验证企业资源调用、任务元数据上报与本机失败事件。
6. 消息中心与会话分享：先完成通知及收件人隔离，再完成会话与附件上传、领取和过期处理；接入前述模块产生的事件。
7. 个人消息渠道、更新与发布：在能力链路稳定后验证微信/飞书本机执行及 Windows/macOS 发布。

## 每步验收

入口、真实接口、持久化及执行分别验收。至少覆盖授权可见、未授权拒绝、刷新/重启保留、网络失败提示、撤权与更新行为。企业密钥不下发；不能把空页面、模拟列表或能点击的按钮报告为功能完成。企业资源更新在安全时机应用，不能任意打断现有任务。

## 导航命名

主要入口尽量采用四字名称：新建会话、专家中心、技能中心、插件中心、定时任务、消息中心；连接器保留通用名称。技能中心分为“企业技能”和“我的技能”；个人支持上传 ZIP 及通过对话创建，个人技能按员工隔离保存在本机。

## 技能中心阶段进度

2026-10-15：桌面入口、企业授权目录、个人 ZIP 导入、对话确认保存和个人技能加载已接通。个人编辑、启停、版本及同名 ZIP 确认替换已补齐；企业技能包加载、摘要校验、版本更新/回滚读取与个人卸载已接入。个人导入的元数据和资源保存在本机员工独立目录，调用名加 my- 前缀，不覆盖企业及内置技能。

## 各模块操作完整性

每个模块交付前核对：列表、搜索、详情、新增/导入、修改、启用/停用、卸载/删除、确认与失败重试、权限撤回和重启持久化。按资源性质选择适用操作，不能把仅有列表和创建报告为整个模块完成；暂不支持的操作明确记入本清单。技能中心已补个人技能编辑与启停，企业技能不由员工卸载或修改。当前验收进度见 2026-10-16 工作日志。
