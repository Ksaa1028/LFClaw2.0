## 工作流转

“工作流转”页面只列出流程元数据，支持标题、员工、部门搜索，以及状态和发起日期筛选。列表展示发起人、当前负责人、截止时间、更新时间和逾期状态。管理员不能读取原文或附件，也不能派单、通过、打回、取消或修改工作。刷新失败时显示错误并保留此前列表。

<a id="lfclaw-管理-web"></a>

“模型用量”按需从管理员接口读取企业模型网关记录，可按 UTC 日期、员工账号和模型筛选，分别查看账号与模型的调用次数、输入/输出/总 Token 和缺失用量次数；列表每页显示 10 条。删除员工或模型后，历史汇总暂以其 ID 标识。个人插件直连外部模型不进入报表。总览本月费用改由服务端汇总返回，管理端初始数据不再携带逐次模型用量记录。

员工激活码复制支持公网 HTTP 页面：优先使用浏览器剪贴板接口，不可用或被拒绝时选中文本执行复制。只有浏览器确认成功才提示“激活码已复制”；失败保留激活码并提示手动选择复制。回归检查从仓库根目录执行 `pnpm exec tsx --test LFClaw/02-管理端/admin-web/tests/clipboard.test.ts`。

连接器认证支持无认证、API Key / Token、自定义凭据字段和远程 OAuth。管理员选择企业共用或员工独立账号；共用账号通过列表中的账号入口连接，独立账号由员工在详情中填写或打开浏览器授权。字段可映射到远程 Header 或 stdio 环境变量，密钥不回显。OAuth 配置、部署回调地址与支持范围见[服务端说明](../server/README.zh.md#通用连接器认证)。

管理页的表格、技能与专家卡片、通知历史以及总览最新动态均每页显示 10 条，分别提供上一页、下一页与总数。筛选专家时从第一页重新显示；删除记录后页码自动回到有效范围。分页只控制当前已加载的数据；最新动态仍由服务端提供最近二十条记录。

员工详情直接指定五项商场数据权限，不勾选任何项表示全部拒绝。切换员工时清空旧权限表单，上一员工迟到的保存响应不会覆盖当前员工。服务端即时失效规则和上游访问限制见[商场权限说明](../server/README.zh.md#商场楼层权限与即时失效)。组件回归从仓库根目录运行 `pnpm exec vitest run --config LFClaw/02-管理端/admin-web/vitest.config.ts`。

连接器表单可选择 Streamable HTTP、旧版 SSE 或 stdio（本地命令）。远程模式填写服务地址和请求 Header；stdio 模式填写启动命令、参数 JSON 数组与环境变量 JSON 对象，例如命令 `npx`、参数 `["-y","@xihe-lab/wechat-mp-mcp-server@latest"]`。命令在企业服务器运行，须在服务器安装相应程序；数据目录也应填写服务器路径。商场数据权限开关及 PNG/JPG 图标适用于三种模式。

Header 与环境变量值仅保存在服务端，管理页读回时置空。地址不变时留空保留 Header；命令和参数不变时环境变量中的空字符串保留原值，删除键移除变量，修改命令或参数后必须重新填写值。参数必须为字符串数组，环境变量必须为名称与字符串值组成的对象；格式错误时保留表单并提示。保存后使用“测试”发现工具，再编辑勾选允许员工调用的工具。执行与权限规则见[服务端连接器说明](../server/README.zh.md#资源与管理接口)。

连接器新增、编辑表单可切换“客户端展示工具”。关闭后桌面连接器中心仍显示该连接器，但不展示工具名称、数量和说明；已授权工具仍能被智能体调用。启停状态和授权范围另行生效。

登录页、侧栏与浏览器图标共用 `public/lfclaw-logo-transparent.png`，原图保存在 `../../04-UI设计/brand/lfclaw-logo-transparent.png`。

管理 Web 供企业管理员使用，员工应用另行建设。页面通过 `/lfclaw/api` 读写 DSH 企业服务，不以浏览器内存或原型数据作为业务数据源。

模型编辑表单的“思考模式”可保持供应商默认值，或为支持 `enable_thinking` 的模型明确开启、关闭。关闭可缩短简单文件任务的模型等待时间；不支持该参数的模型保持默认值。保存后仅影响后续请求。

“消息通知 → 历史通知”可撤回已发布的企业公告，操作前显示确认弹窗。撤回后列表保留标题、发布时间、撤回时间和“已撤回”状态；所有员工的公告收件箱在下次刷新后移除该消息及对应未读数。已撤回公告可再次确认删除，成功后从管理历史和服务端公告记录中移除；未撤回公告不提供删除按钮。

总览的使用趋势和最新动态来自管理员数据接口。趋势显示最近七个 UTC 自然日的员工模型调用次数、已获取 Token（千）和按日去重的活跃员工；请求包括成功、失败与处理中状态，缺失 Token 的次数另行提示。图表柱形悬停可读具体数值。最新动态显示最近二十条已保存的管理员操作，时间按浏览器本地时区显示。进入总览或点击“刷新数据”重新读取；请求失败显示错误并提供重试，无记录显示空状态。数据口径和历史覆盖范围见[服务端说明](../server/README.zh.md#数据与验证)。

最新动态以技能、模型、员工、授权等标签分类，说明操作对象及具体修改项，例如“已修改技能「销售助手」：停用；修改授权范围”。删除记录保留操作时名称；历史记录缺少名称或修改项时明确提示未记录。

部门、员工、模型、技能、连接器、专家的新增、修改和删除，以及通知发布和手动备份，均由服务端处理。保存失败时页面显示错误，不会把失败的新增项目留在列表中。刷新页面会重新获取服务端数据；关闭浏览器后可能需要重新登录，但已保存的数据仍在服务端。版本发布目前尚未接入，页面入口禁用。

新增企业技能只需填写名称并上传 ZIP；描述从包内 `SKILL.md` 的 YAML 元数据自动提取，由服务端保存并供员工端读取。编辑时可更换 ZIP、调整名称与启停状态；更换 ZIP 后服务端自动递增版本号。

技能卡片提供“版本历史”，可查看已保存的修订并确认回退。回退后服务端发布新修订，管理员刷新可见更新，员工资源接口下发新版本；旧技能 ZIP 仍用于历史与备份。

模型和技能的新增、编辑表单可设置分配范围：全员、指定部门或指定员工。四类资源均支持都不授权，保存后拒绝所有员工访问，包括原有个人授权。部门范围覆盖子部门员工。列表展示当前范围，保存后员工可见资源由服务端按实时授权计算。

连接器新增、编辑表单同样可设置全员、部门或员工范围。保存后点击“测试”发现工具，再编辑连接器决定每个工具是否开放；未发现工具时表单显示操作提示。管理员测试只读发现工具，不调用业务数据；不要求配置共享签名密钥。员工详情的“已授权资源”仅展示当前可用的模型、技能、连接器和专家，统一标注“已授权”，不显示授权来源或个人覆盖操作。资源分配在各管理模块配置，已有服务端权限记录保持有效。连接器整体权限与工具开关由服务端在员工读取工具及调用工具时重新校验。

专家中心只展示企业单专家。管理员可配置已发布的阿里云百炼应用、Dify Chatbot / Chatflow 或 WeKnora Agent 并测试连接，也可导入原创单专家并分配范围。管理页不显示或导入企业专家团；已有专家团记录不因此删除。员工口述或输入描述生成个人专家属于员工客户端，不在管理端创建或展示。

员工详情按模型、技能、连接器、专家、专家团分别展示已授权资源和数量。没有授权的分类显示空状态；专家团须同时满足自身及全部成员的有效授权才列入已授权列表。

连接器新增和编辑表单提供独立的“商场数据权限”开关，默认关闭。开启后列表展示“楼层权限”标记；最多一个连接器可开启，其他连接器提示先关闭已绑定项。权限开关与名称、SSE / Streamable HTTP、请求 Header 独立；开启或变更连接配置时保存前检查 MCP 连接及工具目录，失败保留表单及原配置。

员工详情展示已开启商场权限连接器的名称，可勾选营运一层至四层、营运自营五项。全部取消即为无商场数据权限，与连接器及工具授权共同生效。管理员关闭连接器的“商场数据权限”开关后恢复普通 MCP 逻辑，员工楼层设置保留。

部门新增、编辑表单维护名称和上级部门，员工商场数据权限由员工详情单独维护。

数据备份列表提供下载、恢复与删除。删除需要确认，成功后从服务端重新读取列表；归档文件和记录一起删除，不能再用于恢复。

管理端新增、编辑与确认弹窗统一限制在当前窗口内；内容较长时仅表单内容区滚动，标题与底部操作按钮保持可见。模型接口地址和密钥字段不沿用管理员登录表单的浏览器自动填充。

开发预览使用 `pnpm --filter @deepseek-ai/lfclaw-admin-web run dev`。类型检查使用 `pnpm --filter @deepseek-ai/lfclaw-admin-web run typecheck`。业务数据目录由企业服务的 `LFCLAW_DATA_DIR` 决定，见[服务端说明](../server/README.zh.md)。

“系统状态 → 首页文案”可编辑员工端首页口号、标签文字及显示开关，表单提供文字预览。保存失败保留草稿；加载失败可重试。文案属于公开品牌信息，员工端重新打开首页或窗口重新获得焦点时更新。

原创专家通过“导入原创专家”上传或粘贴 JSON 参数，校验后显示只读预览；不再逐项填写名称、描述与工作指令。页面提供参数示例，发布范围和启停状态仍单独设置。修改原创专家保留原 ID，修改参数或发布设置后须重新校验。

“校验并预览”由企业服务执行。若管理端代理返回 HTTP 502/503/504，页面提示检查企业服务并重试；此错误不代表示例或导入 JSON 校验失败。

后端保留旧专家团数据和导入协议供已有记录使用，管理端专家中心不再提供该入口。外部专家使用独立接入入口；可实际调用的来源为阿里云百炼应用、Dify Chatbot / Chatflow 和 WeKnora Agent。Dify 使用应用 API 基础地址、应用 API Key 和可选输入变量 JSON；Agent、旧版 Agent 与 Workflow 不在此阻塞式对话接口的支持范围内。WeKnora 使用 API 基础地址、Agent ID 和具备 `chat` 权限的空间 API Key；表单接受 WeKnora 提供的 HTTP 或 HTTPS 地址，无需额外确认；HTTP 会明文传输空间 API Key。测试时会创建真实会话并调用 Agent，对话结果必须正常结束才显示成功。

外部专家接入只填写身份说明、来源及平台连接参数，并设置企业分配范围和启停状态。技能、连接器和示例问题由外部平台管理，本地接入表单不提供这些字段；保存外部专家时清空旧的本地能力声明。原创专家仍通过导入参数声明能力。

部门表单只维护名称和上级部门。商场数据权限在员工详情直接多选一至四层及营运自营，不提供部门继承；空选择表示禁止全部商场数据访问，员工调换部门不改变其个人权限。
