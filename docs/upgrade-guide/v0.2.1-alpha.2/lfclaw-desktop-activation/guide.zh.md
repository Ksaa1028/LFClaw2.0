# LFClaw 桌面激活

[English](guide.md) | 中文

## 变更

桌面启动进入员工激活页，替代 DeepSeek 登录与 API Key 引导。已有 DeepSeek 凭据不能激活 LFClaw。包名和会话文件保持不变。

应用与随附预设不再设置 LFClaw 身份，关闭 Harness 身份开场白，也不指定模型自报名称。技能、命令、连接器工具及自动续接保留。请新建会话，避免此前的身份回复影响对话历史。

## 迁移

商场数据权限改为仅使用员工个人多选配置。升级前记录原按部门继承员工所需的范围，升级后在员工详情逐人勾选并保存五项权限的任意组合。已有个人配置保持不变，缺少配置或格式错误均无权限；部门楼层和自营字段不再授权。权限接口不再返回 `mode`，并拒绝 `permissions: null`；请发送数组，`[]` 表示禁止全部商场数据访问。

同时更新企业服务与桌面端，以支持 `employee/connector-catalog` 长轮询。同步失败清除旧授权；改权中断在途调用并丢弃旧结果。商场查询由网关强制限定楼层参数，部分权限按单楼层拆分调用。完整五项权限允许全部已授权工具，包括淘气堡和未知工具；部分权限只允许已审计且能限定范围的工具。保持商场权限开关开启，无需共享签名密钥，也不改 MCP 代码或配置；旧 `mcpSecretEnv` 配置可保留但不再使用。网关限制只适用于经过 LFClaw 的调用。

技能 ZIP 发布和桌面安装采用相同规则。旧包若缺少合法 `name`、非空正文或含不安全路径，需修正后重新上传；不自动改写原包。个人技能新增版本及 `lfclaw-enabled` 元数据，缺失时按 `1.0.0` 和启用读取，数字版本仍兼容。新版技能目录响应增加刷新间隔和调用状态，服务端与桌面应同时更新。个人技能清单仅同步指定元数据，不同步正文或附件。

LFClaw Web/桌面组合禁用 `/feedback`、反馈弹窗、消息评分入口和会话遥测上传。已有本地反馈记录保留，仍可通过日志工具读取；企业服务不接收反馈。会话菜单保留下载日志，无需迁移数据。

1. 启动企业服务，向管理员获取员工激活码。
2. 桌面和本地人工测试统一使用 `http://8.216.38.213:39811/lfclaw/api`。重启客户端并清除过时的 `LFCLAW_SERVER_URL` 覆盖值。本地启动器检查正式服务，不再启动本地企业服务。随附激活配置显式启用 `allowInsecureHttp`，自定义配置默认只允许 HTTPS 或本机 HTTP。
3. 输入激活码，重新打开工作区确认已保存凭据通过验证。切换服务地址需要重新激活。

桌面模型选择器使用员工获授权的企业文本模型，通过企业网关调用；桌面 profile 禁用个人 DeepSeek 路由。

自定义企业激活配置需要显式添加 `modelMaxRetries: 1`；企业服务配置需要添加 `modelTimeoutMs: 120000`。桌面 `timeoutMs` 建议设置为 `150000`，以便先收到服务端明确的超时错误。自定义连接器中心配置需要添加 `dataDirectory`、`requestTimeoutMs: 30000` 和 `maxConfigBytes: 1048576`，使用与企业数据分开的本机私有目录保存个人连接器。随附配置已经包含这些字段。企业服务端须同步更新以提供个人连接器策略接口，否则远程个人连接拒绝执行。

桌面新增会话逻辑删除。JSONL 目录中的 `session.deleted` 标记阻止已删除会话再次列出、读取或重用标识；原始日志保留，不擦除工作区文件。不要使用不认识该标记的旧版本打开同一数据目录，否则旧程序可能重新显示已删除会话。

楼层和区域混合范围查询现在返回已授权交集，并明确提示未授权楼层无法获取，不再整次拒绝。服务端和桌面须同步更新：范围拒绝后保留有效工具，真正撤权仍清除工具。完全未授权或参数无效的查询继续拒绝。
