# LFClaw 非商场工具自动可用

[English](guide.md) | 中文

## 变更

此前所有企业连接器都要求 `tools[].allowed` 为 true。现在非商场连接器开放所有已发现工具，包括原先 `allowed: false` 的记录。连接器分配范围、员工状态、启用状态和员工账号要求仍然生效。商场连接器保留逐个工具授权和楼层限制。

## 迁移

1. 检查此前依赖单个工具开关限制访问的非商场连接器。如果员工不能使用所有已发现工具，请禁用连接器或缩小分配范围。
2. 让企业服务端和员工客户端加载更新后的构建。
3. 员工在客户端保存微信公众号 AppID、AppSecret 后，发现的工具直接可用，无需管理员再次授权。
